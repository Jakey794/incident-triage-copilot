# Security Policy

## Supported version

Security fixes are applied to the latest commit on `main`.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Email
`jacob.allan2007@icloud.com` with a concise description, reproduction steps,
and potential impact. You will receive an acknowledgement within seven days.

Do not include API keys, production incident data, or other sensitive material
in a report.

## Handling exposed credentials

If a provider key or deployment credential is exposed, revoke or rotate it in
the provider console immediately. Removing the value from the repository does
not invalidate the exposed credential or remove it from Git history.
